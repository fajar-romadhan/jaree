📌 Panduan Cepat Setup EmailJS: Buka emailjs.com →

📌 Cara Mendapatkan Konfigurasi Firebase (Cukup 2 Menit): Buka console.firebase.google.com →
  1. Buka console.firebase.google.com → Klik Add project (beri nama: jaree).
  2. Di menu sebelah kiri, pilih Build → Firestore Database → Create database → Pilih Start in test mode (Mode Pengujian) → Next → Enable.
  3. Di halaman utama Project Overview, klik ikon Web (</>) → daftarkan aplikasi (nama: jaree-web) → Salin kode firebaseConfig dan tempelkan di kotak di bawah ini → Klik Simpan & Hubungkan Cloud.
Sistem akan otomatis mendeteksi apiKey, projectId, dan pengaturan lainnya dari teks yang Anda tempelkan.
